# sp500-stock-analysis

Objective: Analysis of historical stock performance using data and R

Companies: AAPL,MSFT,AMZN,NVDA,TSLA

Method:
Downloaded stock data from Yahoo
Calculated cumulative returns
Compared investment growth
Visualized the performance using ggplot2

Findings:
Nvidia generated the highest resturn
A $1000 investment in Nvidia significantly outperformed the other companies
Tesla showed higher volatility than Apple and Microsoft 

Tools used:
R
quantmod
tidyverse
ggplot2
